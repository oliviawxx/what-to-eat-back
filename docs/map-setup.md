# 地图与 API Key 说明

## 当前实现（无需 Key）

约饭/榜单页的**地图模式**已接入**微信小程序自带的 `<map>` 组件**，底层使用**腾讯地图**，**不需要申请任何 API Key** 即可：

- 显示地图
- 显示用户蓝点定位（需用户授权位置）
- 设置中心点为武汉大学附近（未授权时使用该默认中心）

因此你现在**不用**去弄高德或其它地图的 Key，直接运行即可看到地图和「查看榜单」「查看约饭」两个按钮。

---

## 若以后要改用高德地图

只有在需要**高德**的额外能力（如高德 POI、路径规划、自定义样式等）时，才需要申请高德 Key 并接入高德小程序 SDK。步骤如下。

### 1. 注册高德开放平台

1. 打开 [高德开放平台](https://lbs.amap.com/)。
2. 使用支付宝或高德账号**注册/登录**。
3. 进入**控制台**。

### 2. 创建应用并添加 Key

1. 在控制台点击 **「应用管理」→「我的应用」**。
2. 点击 **「创建新应用」**，填写应用名称（如「今天吃什么」），提交。
3. 在该应用下点击 **「添加」**，添加 Key：
   - **Key 名称**：随意，如 `miniapp-key`
   - **服务平台**：选择 **「微信小程序」**。
   - **Bundle ID / 包名**：留空或按提示填写（微信小程序有时不强制）。
4. 提交后得到 **Key 字符串**，复制保存。

### 3. 在小程序后台配置

1. 登录 [微信公众平台](https://mp.weixin.qq.com/) → 你的小程序。
2. 进入 **「开发」→「开发管理」→「接口设置」**（或「开发设置」）。
3. 若使用**腾讯地图**：无需配置 Key。  
4. 若使用**高德**：在高德控制台该 Key 的配置里，需要填写小程序的 **AppID**（在微信公众平台「开发」→「开发管理」里可看到），并确保「微信小程序」已勾选。

### 4. 在小程序代码里使用高德

1. 在高德开放平台 **「小程序 SDK」** 文档中下载 **微信小程序 SDK**（通常是一个 `amap-wx.js` 或类似文件）。
2. 将 SDK 放入项目（如 `miniprogram/utils/amap-wx.js`）。
3. 在需要地图的页面：
   - 引入该 JS：`const amap = require('../../utils/amap-wx.js')`
   - 用文档中的方式创建地图、设置 Key、加载图层等（高德小程序 SDK 一般会提供自己的组件或 API，与微信原生 `<map>` 不同）。

注意：使用高德后，往往不再使用微信原生的 `<map>`，而是用高德提供的组件或覆盖物方案，具体以高德当前小程序文档为准。

### 5. 可选：只做服务端调用高德

如果只是**服务端**调用高德（例如逆地理、路线规划），不需要在小程序端显示高德地图：

- 在高德控制台创建 **「Web 服务」** 类型的 Key（不要选「微信小程序」）。
- 在你们自己的后端用该 Key 请求高德 HTTP API，再把结果下发给小程序。
- 小程序端继续用微信原生 `<map>` 显示即可，无需在小程序里配置高德 Key。

---

## 小结

| 方案           | 是否需要 Key | 说明 |
|----------------|-------------|------|
| 当前（微信 map） | **不需要**   | 直接用，已实现。 |
| 高德小程序 SDK  | 需要高德 Key | 按上面 1～4 步申请并接入。 |
| 仅服务端用高德   | 需要高德 Key（Web 服务） | 后端调用，小程序端可继续用微信地图。 |

当前项目**无需**配置高德或其它地图 Key 即可使用地图和两个按钮；若后续要接高德，按本文「若以后要改用高德地图」一节操作即可。
